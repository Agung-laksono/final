# 👤 Tutorial A.3 — Profil & Pengaturan Pribadi

**Durasi video:** ~5 menit | **Role:** Semua pengguna

---

## Tujuan Tutorial

Mengajarkan cara mengatur data diri, mengganti foto profil, dan mengelola keamanan akun pribadi.

---

## Langkah-Langkah

### 1. Membuka Menu Profil

1. Klik **avatar/foto profil** di pojok kanan atas
2. Pilih **Pengaturan** atau langsung ke `/settings/profile`

### 2. Mengubah Data Diri

Di halaman **Profil** (`/settings/profile`):

1. Ubah **Nama Lengkap**
2. Ubah **Username** (digunakan untuk mention/pencarian)
3. Ubah **Nomor HP** (digunakan untuk notifikasi WhatsApp)
4. Upload **Foto Profil** baru:
   - Klik area foto / tombol upload
   - Pilih gambar dari perangkat (format: JPG, PNG, maks 2MB)
   - Foto langsung tersimpan

### 3. Mengubah Password

Di tab **Keamanan** (`/settings/security`):

1. Masukkan **Password Lama**
2. Masukkan **Password Baru**
3. Konfirmasi password baru
4. Klik **Simpan**

### 4. Melihat & Mengelola Notifikasi

Buka halaman **Notifikasi** (`/notifications`):

- Melihat semua notifikasi yang masuk
- Klik notifikasi untuk langsung ke halaman terkait
- Tandai satu notifikasi sebagai **sudah dibaca**
- Tombol **Tandai semua sebagai dibaca**

---

## Yang Perlu Diperhatikan

- Beberapa field (seperti email) hanya bisa diubah oleh **Super Admin**
- Foto profil otomatis ditampilkan di semua halaman dan riwayat transaksi
