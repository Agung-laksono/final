# 🏠 Tutorial A.2 — Dashboard Utama & Navigasi Menu

**Durasi video:** ~7 menit | **Role:** Semua pengguna (demo pakai Manager)

---

## Tujuan Tutorial

Memperkenalkan tampilan dashboard dan cara berpindah antar modul menggunakan navigasi menu.

---

## Langkah-Langkah

### 1. Tampilan Dashboard Utama

Setelah login, Anda langsung masuk ke **Dashboard Utama** (`/dashboard`).

Dashboard menampilkan:
- **Widget ringkasan** — total SO aktif, PO berjalan, stok menipis, dll
- **Grafik tren** — penjualan, pembelian, produksi dalam periode tertentu
- **Alert penting** — item yang butuh tindakan segera

> **Catatan**: Widget yang tampil berbeda-beda tergantung role Anda. Kepala Finance melihat data keuangan, Kepala Gudang melihat data stok, dst.

### 2. Navigasi Menu Utama

Klik ikon **hamburger** atau nama aplikasi di pojok kiri atas untuk membuka **megamenu navigasi**.

Menu dikelompokkan per divisi:
- **INVENTORY** — Gudang & stok barang
- **PEMBELIAN** — Purchase Order & vendor
- **PRODUKSI** — Work Order & resep
- **PENJUALAN** — Sales Order & pelanggan
- **KOMUNIKASI** — Chat WhatsApp
- **KEUANGAN** — Finance & laporan
- **LAINNYA** — Pengaturan, artikel, dll

> **Tips**: Perhatikan **badge angka merah** di samping nama menu — itu menunjukkan jumlah item yang butuh tindakan Anda sekarang.

### 3. Badge Notifikasi di Menu

Badge otomatis muncul ketika ada:
- SO baru menunggu approval (untuk Kepala Sales)
- PO yang perlu diproses (untuk Purchasing)
- Transaksi finance perlu divalidasi (untuk Finance)
- Permintaan barang masuk (untuk Gudang)

### 4. Mengubah Tema (Gelap / Terang)

1. Klik ikon **profil** di pojok kanan atas
2. Klik **Appearance** (Tampilan)
3. Pilih mode **Light**, **Dark**, atau **System** (ikuti tema OS)

### 5. Menginstal Aplikasi sebagai PWA di HP

1. Buka aplikasi di browser HP (Chrome/Safari)
2. Muncul prompt **"Tambahkan ke Layar Utama"** → ketuk **Tambahkan**
3. Atau: buka menu browser → ketuk **Install App**
4. Ikon aplikasi muncul di layar utama HP

---

## Yang Perlu Diperhatikan

- Tampilan navigasi berbeda per role — menu yang tidak ada aksesnya tidak ditampilkan
- Refresh halaman jika badge tidak update setelah melakukan aksi
