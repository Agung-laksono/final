# 🔑 Tutorial A.1 — Login & Keamanan Akun

**Durasi video:** ~5 menit | **Role:** Semua pengguna

---

## Tujuan Tutorial

Memandu pengguna pertama kali untuk masuk ke sistem dan mengamankan akunnya.

---

## Langkah-Langkah

### 1. Membuka Aplikasi

Buka browser dan akses URL aplikasi. Anda akan diarahkan ke **halaman Login**.

> **Tips PWA**: Di perangkat HP, ketuk ikon aplikasi yang sudah diinstal untuk langsung membuka tanpa browser.

### 2. Login dengan Email & Password

1. Masukkan **Email** yang sudah didaftarkan admin
2. Masukkan **Password**
3. Klik tombol **Masuk**

### 3. Login dengan Passkey (Biometrik)

Passkey memungkinkan login tanpa password menggunakan sidik jari atau face ID.

1. Klik tombol **Login dengan Passkey**
2. Ikuti prompt biometrik dari perangkat Anda (fingerprint/face ID)
3. Anda langsung masuk tanpa mengetik password

> **Catatan**: Passkey harus diaktifkan terlebih dahulu di menu **Pengaturan → Keamanan**.

### 4. Mengaktifkan Two-Factor Authentication (2FA)

Lapisan keamanan tambahan — setiap login akan meminta kode OTP.

1. Setelah login, buka **Pengaturan → Keamanan** (`/settings/security`)
2. Klik **Aktifkan Autentikasi Dua Faktor**
3. Scan QR Code dengan aplikasi authenticator (Google Authenticator / Authy)
4. Masukkan kode 6 digit untuk konfirmasi
5. Simpan **Recovery Code** di tempat aman

---

## Yang Perlu Diperhatikan

- Jangan bagikan password ke siapapun
- Gunakan password yang kuat (minimal 8 karakter, kombinasi huruf + angka + simbol)
- Jika lupa password, hubungi **Super Admin** untuk reset
