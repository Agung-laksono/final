# 🎬 Panduan Seri Video Tutorial Aplikasi

Dokumen ini adalah indeks lengkap seri video tutorial pemakaian sistem ERP ini, dikelompokkan per **divisi dan role pengguna**. Setiap seri memiliki sub-topik tersendiri yang bisa diakses di sidebar.

---

## 📋 Daftar Role Pengguna

| Role | Divisi | Akses Utama |
|------|--------|-------------|
| **Super Admin** | Sistem | Semua fitur & pengaturan |
| **Manager** | Semua | Semua modul |
| **Kepala Gudang** | Inventory | Full inventory + lihat SO & PO |
| **Staf Gudang** | Inventory | Operasional gudang harian |
| **Staf Gudang PPIC** | Inventory + Produksi | Permintaan & pemenuhan bahan |
| **Staf Gudang Fulfillment** | Inventory + Pengiriman | Packing & pengiriman SO |
| **Kepala Purchasing** | Pembelian | Full purchase + approval |
| **Staf Purchasing** | Pembelian | Buat PO & kelola vendor |
| **Kepala Sales** | Penjualan | Full sales + approval SO |
| **Staf Sales** | Penjualan | Buat SO, input pembayaran |
| **Kepala Finance** | Keuangan | Full finance + validasi bayar |
| **Staf Finance** | Keuangan | Catat transaksi & transfer |
| **Kepala Produksi** | Produksi | Full produksi + resep |
| **Staf Produksi** | Produksi | Update work order |
